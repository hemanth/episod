SYSTEM SCHEMATIC // 01

Episod Gateway Architecture

Monochrome architectural schematic illustrating stateful conversational DAGs, prefix affinity routing, and human-in-the-loop tool execution for stateless inference engines.

DAG MEMORY

Immutable Turns

Conversations form a directed acyclic graph persisted in SQLite WAL. Counterfactual branches and forks preserve previous paths without mutating history.

PREFIX CACHING

Consistent Ring

Consistent hashing pins session tokens and common system prompts to the same inference replica, maximizing GPU KV-cache hit ratios.

HUMAN-IN-THE-LOOP

Approval Gate

Configurable execution policies pause the SSE stream when sensitive tools trigger, resuming execution only after operator sign-off.
